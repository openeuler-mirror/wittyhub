# SkillHub 简介

## SkillHub 是什么

SkillHub 是一个面向开发者与 AI 用户的 **AI Skills 检索与分发平台**。你可以把它理解成一个"AI 技能的广场"——来自 openEuler 社区、企业组织和个人开发者的 AI 技能被汇聚在这里，供所有人发现、评估、使用和贡献。

- **想使用 AI 技能**：搜索并筛选，快速找到当前任务需要的 AI 能力，一键安装使用。
- **想贡献 AI 技能**：把可复用的经验沉淀为 Skill，分享给更多开发者使用。
- **企业 / 团队**：把组织内部沉淀的能力对外整理发布，供他人调用或协作。

SkillHub 的口号是：

> **与开发者共同探索、评估、贡献 AI 技能。**

## 我们帮你解决什么

### 快速找到想要的 Skill

那些散落在几十上百个仓库里的 AI 技能，在这里被统一汇聚起来。你只需要搜索关键词，或者按「领域分类 / 贡献者 / 安全等级」筛选，就能快速定位到你需要的那个 Skill，不用再逐仓库翻找。

### 放心地使用每个 Skill

每个上架的 Skill 都经过了**自动化的安全审查**，并附有一个量化的风险分数和完整的安全评估报告。用一个 Skill 之前，你能直观地看到它安不安全、风险有多高，从源头避免引入不靠谱的代码。

### 方便地接入你的环境

找到合适的 Skill 后，一条命令即可安装到本地 Agent 环境，也可以直接下载 ZIP 包。无论你用哪种方式，都能快速把别人的能力变成自己手中的工具。

### 低门槛地贡献你的 Skill

你不需要任何平台运维经验。只要有一个包含 `SKILL.md` 的公开仓库，在 `openEuler-skills` 仓库里登记一个配置文件，就能把你的 Skill 上架，审核通过后它会**同步展示在首页**，供其他开发者使用。

## 哪些 Skill 会出现在这里

Skill 来自三类贡献者：

| 来源 | 说明 |
|------|------|
| 社区 SIG | openEuler 社区各 SIG 维护的能力 |
| 企业组织 | 各大企业官方发布的 AI 能力与插件 |
| 个人开发者 | 个人分享的可复用技能 |

这些 Skill 会被归入直观的领域分类，例如「研究设计、开发构建、工程编译、质量验证、发布部署、监控运维、性能优化、安全加固」等，方便按场景浏览。

## 一条 Skill 从贡献到上架的旅程

```
贡献 → 审核 → 扫描入库 → 安全审查 → 上架展示 → 被检索与安装
```

你的技能提交后，平台会自动完成剩余的工作：识别能力信息、智能归类、安全审查、存档展示——你只需要专注优化 Skill 本身。
