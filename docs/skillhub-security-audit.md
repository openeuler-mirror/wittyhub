# 安全评估：你的 Skill 安不安全

> 每个上架的 Skill 都经过 **NVIDIA SkillSpector** 的安全审查，并附有一个清晰的安全评估报告，让你在安装前就能直观判断：**这个能力能不能放心用。**

## 一句话理解

AI 技能在安装后会被 Agent 以"可信"的方式执行，一旦带毒后果很严重。研究表明：**约 26% 的 Skill 含有漏洞，约 5% 疑似存在恶意意图**。SkillHub 每个 Skill 都有一个 **0-100 的风险分数**（分数越高越危险），并换算成你一眼就能看懂的安全等级。你不用懂代码，也能判断一个 Skill 的风险高低。

## 谁来审查：NVIDIA SkillSpector

SkillHub 的安全审查由 **NVIDIA SkillSpector** 完成——这是 NVIDIA 开源的 AI Agent 技能安全扫描器（已通过 Verified Skills 流水线，为 AI 技能出版前做扫描、评估与签名）。它不只看你写了什么，还会分析"这些代码真跑起来会怎样"，重点排查以下几类风险：

- **提示注入**：偷偷篡改指令、隐藏恶意指令的攻击手段；
- **数据外泄**：把环境变量、密钥、文件偷偷往外传；
- **权限提升 / 过度权限**：Skill 索要超出任务所需的权限；
- **供应链风险**：依赖了可疑或带漏洞的第三方组件；
- **系统提示泄露 / 记忆投毒**：偷窥系统指令或污染 Agent 长期记忆；
- **危险代码**：会被 Agent 执行的高危脚本或命令。

它内置了 **70 种漏洞检测规则**，覆盖 17 个安全类别，能识别从常见注入到 YARA 已知恶意样本的大量问题。

## 审查怎么做到"可信"

SkillSpector 采用**两阶段分析**：

1. **静态分析**：快速扫描代码，匹配已知漏洞模式；
2. **LLM 语义评估**：借助大模型理解 Skill 的实际意图，识别难以靠规则发现的行为。

同时，它还会联动实时漏洞库：通过 SC4 查询 **OSV.dev** 获取最新 CVE（通用漏洞披露）数据，即使离线也有内置兜底，尽量确保对新出现的威胁也能及时发现。

## 你会在哪看到评估结果

- **列表页**：按「安全等级」筛选，快速挑出足够安全的 Skill。
- **详情页（顶部）**：醒目标注该 Skill 的安全等级标签。
- **评估详情**：可以查看某个 Skill 的完整安全评估报告，了解它到底可能"危险"在哪。

## 五个安全等级

基于 0-100 风险分，SkillHub 换算为五档方便理解的安全等级：

| 等级 | 分数区间 | 意味着什么 |
|------|---------|-----------|
| 🟢 安全 | 0-20 | 无显著风险，可以放心使用 |
| 🔵 低风险 | 21-50 | 只有轻微告警，基本可控 |
| 🟠 中风险 | 51-80 | 存在一定隐患，建议谨慎评估后使用 |
| 🔴 高风险 | 81-100 | 存在较严重问题，不建议直接安装 |
| ⚪ 未检测 | — | 正在审查中或尚未评估 |

> 需要留意：**尚未完成安全审查的 Skill 不会出现在公开列表里**。也就是说，你看到的每个已上架 Skill 都经过了安全把关。

## 评估报告都讲些什么

一份评估报告会说明「这个 Skill 整体安不安全、需要注意什么」：

- **综合风险等级与分数**：一眼看清整体风险。
- **问题清单（风险信号）**：每一个被发现的隐患，都写明「问题是什么、严重程度如何、建议怎么处理」。
- **审查结论与建议**：一份通俗的结论，明确告诉你这个 Skill **是否适合安装**（`safe to install`）、需要注意哪些风险点。

## 安全审查是如何自动运行的

全程自动化，无需人工：

1. Skill 提交并登记后，平台把 Skill 的代码交给 SkillSpector 进行深入扫描。
2. 扫描问题会被整理成「问题清单」，每个问题带严重度（如 低 / 中 / 高 / 严重）。
3. 系统综合所有问题，评定 0-100 风险分并换算成安全等级，写回 Skill 并更新展示。
4. 对于新上架或批量入库的 Skill，平台会在后台持续跟进扫描结果，直到得出可靠结论。

## 多一层：平台本身的防护

为了让整个平台本身也是安全的，SkillHub 只接受来自**可信代码托管平台**、采用**正规仓库地址**的 Skill。那些可疑的内网地址、非常规端口或来源不明的链接，会在登记时就被拦下，避免平台被恶意利用。
